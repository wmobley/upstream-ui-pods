# API Reference

Use the REST API when you are building a custom integration or want direct HTTP access to Upstream data.

Most end users should start with the web UI or Python SDK. The API is useful for:

- Lightweight integrations.
- Custom dashboards.
- Data transfer scripts in languages other than Python.
- Checking exact request and response behavior.

See the [REST API quickstart](../getting-started/quickstart-api.md) for common examples.

For multi-project deployments, make sure you call the API URL for the project instance you want to access. See [Projects and API URLs](../concepts/projects-and-api-urls.md).
