# Administration

Administrators can manage user roles, metadata schemas, and pod bundles.

## Administrative features

| Feature | Description | Page |
| --- | --- | --- |
| **User roles** | Control who can perform administrative actions | [User roles](user-management.md) |
| **Metadata schemas** | Define custom fields for campaigns, stations, and sensors | [Metadata schemas](metadata-schemas.md) |
| **Pod bundles** | Configure new Upstream instances | [Pod bundles](pod-bundles.md) |
| **Monitoring** | Monitor system health and usage | [Monitoring](monitoring.md) |
| **Backup and restore** | Backup and restore data | [Backup and restore](backup-restore.md) |

## Access control

Administrative features require the `admin` role. Regular users can:

- View campaigns they have access to
- Manage their own stations and data
- Upload, export, and publish data

Admins can additionally:

- Manage user roles
- Configure metadata schemas
- Create pod bundles
- Access system monitoring
