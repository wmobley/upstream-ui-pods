# Sensor Visualization

Upstream provides temporal and spatial visualizations for exploring sensor data. When you select a sensor, the dashboard shows charts and maps for that sensor's measurements.

## Temporal charts

Temporal visualizations show how a sensor's values change over time.

- **Line chart with confidence intervals** — aggregated trend view with variation bands
- **Scatter plot** — individual measurement points for detailed inspection

Use the brush/zoom controls to focus on specific time ranges. Hover over points for detailed tooltips.

See [Temporal visualizations](../../visualization-guide/temporal-visualizations.md) for details.

## Spatial maps

Spatial visualizations show where measurements were collected and how values vary by location.

- **Heat Map** — color-coded points for comparing measurement intensity across locations
- **Geometry/Route Map** — interactive map for exploring paths and individual locations

See [Spatial visualizations](../../visualization-guide/spatial-visualizations.md) for details.

## Switching between sensors

Use the sensor selector on the station dashboard to switch between sensors. Each sensor has its own measurement data and visualization panels.

## Exporting visualization data

The export actions on the station dashboard let you download the data currently shown in the visualizations. Use filters to control what gets exported.
