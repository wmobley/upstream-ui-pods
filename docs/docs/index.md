# Upstream Documentation

Upstream is an environmental sensor data platform that helps researchers, field data managers, and project administrators collect, manage, visualize, access, export, and publish environmental sensor data.

## Choose your interface

Upstream supports multiple ways to work with your data:

- **[Web UI](getting-started/quickstart-web-ui.md)** — Interactive visualization, data exploration, and campaign management through your browser.
- **[Python SDK](getting-started/quickstart-python-sdk.md)** — Programmatic access for researchers, notebooks, and automated data pipelines.
- **[REST API](getting-started/quickstart-api.md)** — Direct HTTP access for custom integrations and tools.

## What you can do

- Create and manage **campaigns**, **stations**, and **sensors**
- Upload sensor and measurement CSV data
- Visualize data with temporal charts and spatial maps
- Export data as CSV or GeoJSON
- Publish curated datasets to [CKAN](https://ckan.tacc.utexas.edu) for discovery and reuse
- Manage user roles, metadata schemas, and pod bundles
