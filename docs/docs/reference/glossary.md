# Glossary

| Term | Definition |
| --- | --- |
| **Campaign** | Top-level organizational unit grouping related stations |
| **Station** | A physical location where sensors are deployed |
| **Sensor** | A measured quantity at a station (e.g., temperature, flow rate) |
| **Alias** | Unique name for a sensor used in CSV files and data access |
| **Measurement** | A single observation record with timestamp, coordinates, and values |
| **CKAN** | Comprehensive Knowledge Archive Network — open-source data management system |
| **Tapis** | TACC's API infrastructure for authentication and job management |
| **IOP** | Intensive Observation Period — a focused data collection period |
| **GeoJSON** | Geographic JSON format for spatial data |
| **CSV** | Comma-Separated Values — tabular data format |
| **IANA timezone** | Standard timezone names (e.g., `America/Chicago`, `UTC`) |
| **PostGIS** | Spatial database extension for PostgreSQL |
| **Confidence interval** | Statistical range summarizing measurement variation |
| **Downsampling** | Reducing the number of displayed points for performance |
| **LTTB** | Largest-Triangle-Three-Buckets — algorithm for visual downsampling |
| **Pod** | Deployment unit in the Upstream platform |
| **Metadata schema** | Custom fields defined by administrators for campaigns, stations, or sensors |
