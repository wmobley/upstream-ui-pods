# Visualization Guide

Upstream provides temporal and spatial views for exploring station measurements.

## Temporal visualizations

Use temporal charts when you want to understand how a sensor changes over time. Upstream includes line/confidence views and scatter-style point inspection in the same user workflow.

See [Temporal visualizations](temporal-visualizations.md).

## Spatial visualizations

Use spatial maps when you want to understand where measurements were collected and how values vary across locations.

See [Spatial visualizations](spatial-visualizations.md).
